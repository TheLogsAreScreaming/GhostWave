# LilyGO T3-S3 (SX1262 version)

> **Untested on hardware.** This build compiles, and nobody has run it on this board.

Build env: `t3s3` (`cd firmware/mcu && pio run -e t3s3`). Pins come from meshtastic/firmware @ 771efca, `variants/esp32s3/tlora_t3s3_v1`.

From `firmware/mcu`, flash with `pio run -e t3s3 -t upload`. If several serial devices are attached, select this board explicitly with `--upload-port PORT`. Close any serial monitor before uploading. The phone app connects over Bluetooth (pairing key `654321`), as on the nRF boards. Built, not yet tried on this board.

Fit the antenna first, then type `tx on`: a fresh board only receives until you do. GPS, buttons and other extras are not used yet.

The T3-S3 is also sold with SX1276 and SX1280 radios. This build only works on the SX1262 version.

## After an interrupted upload

Reconnect this board over USB, select its serial port again, then rerun the same `t3s3` upload command. If the port does not appear, use the manufacturer's download-mode procedure for the exact PCB revision. After upload, open `pio device monitor --port PORT --baud 115200` and run `status` to check the running firmware before a radio test.
