# Hardware qualification results

Status: planning draft. Implementation and verification are pending.

## Scope

Create and complete per-board records for boot, identity storage, radio operation, Bluetooth where supported, encrypted DMs, SOS acknowledgment/cancellation, reconnects and recovery. Record revision, source SHA, firmware hash and test setup.

## Dependencies

Builds and flashing guides; physical boards and operator results

## Acceptance criteria

- [ ] Only actual observed results count as passes. Record failures and untested cases explicitly. No fabricated measurements or assumed compatibility.
- [ ] Review changes and record validation on the exact final commit.

This document does not implement flashing support, publish a release, or establish hardware qualification.
