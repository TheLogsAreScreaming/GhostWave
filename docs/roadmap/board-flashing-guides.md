# Flashing and recovery guides for selected boards

Status: planning draft. Implementation and verification are pending.

## Scope

Write board-specific installation, bootloader entry, recovery and first-connection guides for all 11 targets. State required cables, radio band, firmware format and supported peripherals.

## Dependencies

Compatibility records; validated installer paths

## Acceptance criteria

- [ ] Instructions match exact artifacts and bootloaders. Cite sources and clearly separate source-derived instructions from steps verified on hardware.
- [ ] Review changes and record validation on the exact final commit.

This document does not implement flashing support, publish a release, or establish hardware qualification.
